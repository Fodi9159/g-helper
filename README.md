# G-Helper (custom fork)

> ⚠️ **Custom fork** by [Fodi9159](https://github.com/Fodi9159) — auto-synced with [seerge/g-helper](https://github.com/seerge/g-helper), plus:
>
> GPU / power
> - ⚡ **Core Voltage slider** — 400–1300 mV in 5 mV steps (NVAPI boost lock), applied without touching clocks; `Default` marker at stock voltage with one-click unlock
> - 🕐 **Core Clock Limit slider** — separate clock cap, independent from voltage
> - ⌨️ **Click-to-type values** — click any slider value to type it directly (Enter commits, Esc cancels)
> - 🔋 **Per-mode power limits** — independent CPU PPT / crossload / GPU-to-CPU / CPU-temp sliders per mode; unchecking Apply reverts hardware to OEM defaults for that mode
> - 🚀 **Boot OEM apply** — live SMU/OEM constants applied on startup when Apply Power is unchecked
>
> Keys / screen / theme
> - 🎮 **F-row bindings** — F1–F11 actions incl. Bluetooth, CPU boost, Windows theme toggle (+Fn+F5)
> - 🌗 **Fast Windows theme toggle** — light/dark switch without the lag
> - 🟢 **FreeSync toggle + auto refresh on lid open** — from the screen panel
>
> Fixes & builds
> - 🔧 **Fan sensor swap fix** — corrected CPU/GPU readings
> - ⌨️ **Keyboard backlight fix** — stays on while typing
> - 🏭 **Factory Defaults** — no longer switches the Windows power plan
> - 📦 **Self-contained releases** — single `GHelper.exe`, auto-update points at this fork

Full documentation is at [docs/README.md](docs/README.md).
